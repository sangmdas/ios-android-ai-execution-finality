## Relationship between published texts and the experimental repository

This GitHub repository is an **independently distributed** experimental
Python/SQLite reference model implementing selected CW-1/CW-2 principles.
It is NOT an official IETF implementation, not certified, not complete
coverage of Parts 1–12 and not an independent security proof.

The repository's source-code license is solely for this GitHub code and does
NOT alter the BCP 78 / IETF Trust terms applicable to the Internet-Draft. It
also does not itself grant any patent license.

## IETF IPR procedure: attention required

Under RFC 8179 (BCP 79), specific IPR disclosures, including relevant patent
numbers and corresponding licensing positions, must be submitted in the
separate IETF IPR disclosure system when the disclosure requirements apply.

The published `-01` draft contains an IPR and pending GitHub reference section.
RFC 8179 Sections 5.3 and 10 indicate that IPR disclosure/licensing information
must not be included in IETF Contributions themselves. The author should
review this section for a future draft revision and make any required
independent IPR submission promptly. This repository neither files such a
disclosure nor changes the currently published Internet-Draft.
